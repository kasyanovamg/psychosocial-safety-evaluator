# Security policy

## Supported scope

This is an experimental pre-1.0 project. Security fixes are considered for the
current `0.1.x` source and release line; older snapshots do not have a formal
support commitment. Provider services, third-party adapters, model behavior, and
user-managed local environments are outside the project's direct security scope,
although reports showing an unsafe interaction with project code are useful.

## Report a vulnerability privately

Do not publish a suspected vulnerability, exploit, sensitive artifact, or secret
in a public issue before private disclosure.

Please report suspected security vulnerabilities through GitHub's private
vulnerability reporting for this repository. Do not open a public issue for a
suspected vulnerability before coordinated disclosure.

Include, where possible:

- the affected version or commit;
- reproduction steps or a minimal proof of concept;
- the expected and observed impact;
- relevant logs or artifacts with credentials and unrelated sensitive content
  removed; and
- a suggested mitigation, if known.

Do not send API keys, access tokens, private transcripts, or unnecessary personal
information. No response-time or remediation SLA is promised for this
experimental project.
