# Content provenance

Scenarios, rubrics, prompts, and documentation in this repository were created
for the Psychosocial Safety Evaluator project, with AI assistance where
applicable. Evaluation transcripts and demo outputs are synthetic artifacts
generated during controlled model evaluation and are not real-user
conversations.

In particular:

- The Relational Sycophancy scenario pack was created specifically for this
  project. Its situations and user turns are synthetic.
- Rubric v0.2, judge prompt v0.3, and the methodology and documentation were
  developed specifically for this project.
- Files in `manual_judge/` are archived project evaluation samples. Their user
  turns come from synthetic project scenarios, and their assistant and judge
  responses are controlled model-evaluation outputs—not private conversations.
- The packaged reference demo contains synthetic scenario conversations and
  model-generated target and judge outputs from a controlled evaluation run. It
  contains no real-user transcripts.
- Test fixtures are synthetic project test material.

AI assistance was used where applicable in developing project-authored
materials. Model-generated output is identified here by its role in an
evaluation artifact; the repository owner does not claim to have personally
authored that output word-for-word.
