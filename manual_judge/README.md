# Archived manual judge material

This directory preserves early manual judge requests, responses, and immutable
import attempts for development traceability and compatibility tests. It is
historical project material, not the current V1 demo, reference configuration,
validation dataset, or primary evaluation workflow.

See [Archived initial manual judge smoke tests](../docs/manual-smoke-tests.md)
for the historical configuration and interpretation of these records. Do not
rewrite the saved attempts to match current prompt or runtime versions.
